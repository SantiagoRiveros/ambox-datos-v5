NUMPY:
Numpy es una libreria de Python orientada principalmente al calculo numerico y al trabajo eficiente
con arrays.

En lugar de trabajar simplemente con:

numeros = [10, 20, 30, 40]

podemos utilizar:
numeros = np.array([10, 20, 30, 40])

Lista vs Numpy Array 

Lista:

numeros = [10, 20, 30, 40]

Array:

import numpy as np

numeros = np.array([10, 20, 30, 40])

DIFERENCIAS IMPORTANTES

Característica             Lista de Python              Array de NumPy
────────────────────────────────────────────────────────────────────────
Tipo de datos              Puede mezclar tipos          Normalmente un tipo homogéneo
Operaciones matemáticas    Más limitadas                Muy potentes y rápidas
Rendimiento numérico       Más lento                    Más rápido
Memoria                    Consume más                  Más eficiente
Dimensiones                Listas anidadas              Multidimensional nativo
Funciones matemáticas      Bucles o funciones           Operaciones vectorizadas
Necesita instalación       No                           Sí (numpy)

Una de las ventajas principales es que podemos realizar operaciones sobre todos los elementos

PANDAS:
Es una biblioteca especializada en la manipulacion y el analisis de datos
OFrece estructuras de datos y operaciones para manipular tablas numericas 
y series temporales.

Dataframes:
Son estructuras tabulares de datos, se usan especialmente para analisis de datos

Dato tabular:
Basicamente son datos bidimensionales, con columnas y filas

Dataframe -> tabla
columna -> Variable 
Fila -> Registro
indice -> posicion de la fila

cuando en un dataframe ponemos corchetes
estamos modificando el "contexto" de lo que se muestra

por ejemplo -> dataframe["producto"]
Esto, lo que hace, es que toma la columna producto
pero no eslo uniuco que podemos hacer para cambiar el contexto
de lo que se muestra dentro de los corchetes
basicamente -> PODEMOS CREAR FILTROS DENTRO DE LOS CORCHETES
